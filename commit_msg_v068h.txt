## 设计决策

- **GBK 兼容**: PowerShell 默认 GBK 不能输出 emoji 🟢🔴, 改用 ASCII ▲▼
- **HTML 表格独立输出**: 邮件附件直接 attach, 不用 markdown → HTML 二次转换
- **Y 轴 tick 让 MaxNLocator 自动选**: 不同价格范围自动适配
- **缺数据自动跳过**: `compute_1d_change` 返回 None 时不进表格, 不报错

## Lesson (写进 future design)

- **可视化"接近价格"原则**: ylim 应该跟数据范围匹配, 不要让大量空白浪费屏幕
- **表格 + 颜色编码**: 即使 20 标的, 表格一眼看出 1d 涨跌幅
- **GBK 兼容性**: Windows PowerShell 默认 GBK, 输出 emoji 会 UnicodeEncodeError
  - fix: ASCII (▲▼) 或 reconfigure stdout encoding = "utf-8"
