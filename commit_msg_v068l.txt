## 设计决策

- **Orchestrator 模式**: 不 copy-paste 各 step 逻辑, import 现有函数
  - fetch_all.main() / src.report.render_full_report() / src.performance_dashboard
  - 每步独立 try/except, 失败不阻塞 (cron 友好)
- **CLI 优先 + 函数次之**: main() 调 run_daily_report() 函数, smoke test 也调函数
- **skip 参数细粒度**: 4 个独立 flag, smoke test 跳过慢的部分 (fetch + html + dashboard)
- **alerts placeholder**: 即使 P8-6 还没写, daily_report 也建空 alerts_<date>.json
  - 后续 P8-6 healthcheck runner 写第一行 alert 时不报错
- **不传 date_str 默认今天**: 同一函数可 cron 跑 (date=今天) 或 backfill (date=历史)

## Lesson 写进 future engineering (新)

- **Orchestrator 不 copy-paste**: 大 pipeline 是 import + 调函数, 不是从零写
- **Smoke test 用 skip 参数避开慢 step**: daily_report smoke 5.3s 而非 5-10min
- **每步独立 try/except**: 跟 failing fast 相反, 但 cron 友好
- **Placeholder 文件让 pipeline 不挂**: 上下游模块不必同时 ready
