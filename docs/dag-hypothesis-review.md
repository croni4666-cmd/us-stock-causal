# 低可信DAG与可证伪命题

DAG只作为候选假设。图内可以找到调整集合，并不意味着图的箭头、无遗漏混杂或真实因果效应得到验证。现有因果查询、SCM情景和CATE结果均保留数值，但默认输出 `low_hypothesis_only`、`not_established`、`insufficient`；`causal_probability` 始终为 `null`。

本入口评估的是**命题成立的证据支持程度**，没有把p值、模型置信区间或检验通过率变成命题为真的百分比。它也不会凭搜索结果、引用数量或AI叙述给假设背书。

## 可以执行的观察约束

目前只有两个范围明确的检验：

- `conditional_linear_zero`：指定变量和控制项后，线性关联系数在登记的 `[-tolerance, tolerance]` 内。区间完全落在容忍带内才提供有限的条件支持；精确零假设的“不拒绝”不计支持。它不是一般条件独立性检验。
- `lagged_directional_association`：指定滞后观察数、方向及最小系数量级。整个区间超过登记阈值才提供支持；整个区间与命题相反才记录反对。滞后关系不识别因果方向。

未给出可执行约束的因果箭头、缺失变量或未经核验的前提仍完整显示为“当前无法检验”。不会补数据或将这些项删除后再宣称模型已验证。

OLS使用预先声明的HAC滞后数和近似区间，对登记的全部条目做Bonferroni多重比较控制，包括无法检验项和重复项。该方法依赖线性模型及相关统计条件，不保证适用于任意金融过程；没有实现完整的DAG独立性套件、非线性检验或因果方向识别。

## 支持等级

| 输出 | 含义 |
|---|---|
| 证据不足 | 未得到合格支持；不拒绝、事后探索和缺口均可导致此状态 |
| 有限条件支持 | 登记的可观察约束在近似模型和声明协议下获得支持；因果效应仍未建立 |
| 存在反对证据 | 登记的观察约束受到反驳；不是自动推翻整个DAG |
| 证据冲突 | 同一观察命题存在支持与反对记录；不会多数表决隐藏反例 |

正反命题分别展示，不把不同变量、不同阈值或不同方向凑成一次投票。相同检验不会计为独立复现；不同输入哈希也不证明样本独立。跨次运行的重复时间声明冲突或区间选择冲突都会限制升级，聚合顺序不影响结果。

登记晚于窗口开始的支持和反对记录都只算探索。窗口开始使用纽约当地09:30作保守界限；登记时间只是声明，系统没有可信登记服务器，也无法证明研究者事前没看过数据。即使登记声明早于窗口，也最多获得有限条件支持。

## 输入与使用

数据为Parquet，索引须为唯一递增、不含时区的每日日期；须覆盖完整登记窗口。缺失行会报告并剔除，不插值；至少80个完整观察且满足控制项数量约束。数据的 `attrs['column_units']` 必须与协议显式单位一致。单位是声明，仍需核验上游转换；收益率差、价格回报和利率水平不能混用。

登记文件示例（示例日期和阈值需要按自己的事前设计修改）：

```json
{
  "schema_version": 1,
  "alpha": 0.05,
  "hypotheses": [{
    "id": "H1",
    "statement": "上一观察期收益率变化与下一期QQQ回报的负向线性关联超过指定量级",
    "kind": "lagged_directional_association",
    "treatment": "TNX_bp_change",
    "outcome": "QQQ_pct_return",
    "controls": [],
    "units": {"TNX_bp_change": "bp_change", "QQQ_pct_return": "pct_return"},
    "lag_observations": 1,
    "direction": "negative",
    "minimum_effect": 0.01,
    "start": "2027-01-04",
    "end": "2027-12-31",
    "registered_at": "2026-12-01T00:00:00+00:00",
    "hac_lags": 5
  }]
}
```

```console
python -m examples.hypothesis_report --registry registry.json --data input.parquet --output output/hypothesis_report.md --json-output output/hypothesis_report.json
```

入口完全离线。Markdown默认展示完整实际协议、阈值、区间、缺失记录、登记限制和输入哈希，便于发现文字标题与实际检验条件不一致。异常的单项阈值保留为不可检验诊断，不中断有效的其他命题；非法注册表结构则明确失败。

完整预登记还应包括数据选择、转换、缺失处理、控制项、样本窗口、阈值和检验族，并在真实未来留出样本中锁定协议。目前没有认证预登记、校准概率、独立样本认证或完整因果识别，因此不输出高可信、已证明或可交易结论。
