# 黄金、美债、纳斯达克资产专用归因与因果研究设计

状态：第一阶段实施；后续阶段为明确的研究路线，不代表已经完成。
基线：PR #7，1de358d。这里的“真实持仓”指基金持仓，不涉及用户账户。

## 1. 产品目标与输出边界

用户输入标的、起止交易日和分析模式，得到可核对的数据来源、回报口径、
资产结构、可计算的贡献及未解释部分。适用对象：GLD、GC=F、IEF、TLT、
QQQ、^NDX、^IXIC，以及美国国债收益率序列。价格指数、ETF、期货、
收益率不能互相替代。^IXIC 是纳斯达克综合指数；QQQ 跟踪纳斯达克100，
QQQ 持仓不能代表 ^IXIC 或作为 ^NDX 官方指数权重。

所有结果必须具有明确标签：

| 层级 | 能回答的问题 | 第一阶段状态 |
|---|---|---|
| 回报描述 | 哪个序列在什么时间变了多少 | 实现 |
| 持仓结构 | 基金实际持有什么、覆盖率是多少 | 实现 |
| 机械贡献/敏感性近似 | 期初权重或久期对应的金额/回报贡献 | 满足输入条件时实现 |
| 统计关联 | 因子变化与回报在样本中的关联 | 后续专用模型；已有通用回归保留原标签 |
| 条件性因果效应 | 已识别外生冲击带来的响应 | 需要专门冲击数据与识别审查 |

缺少输入必须返回 unavailable 和具体原因，不能自动替换成静态估计权重、
行业ETF回报或人工DAG结论。没有用户持仓也可以使用全部基金分析功能。

## 3. 时间与证据合同

每个 source document：`schema_version=1`、symbol、provider、source_url、
SHA256、retrieved_at（带时区UTC）、available_at、as_of、kind、rows、warnings。
`available_at` 第一阶段保守等于实际下载时刻，不能凭所属日期倒填发布日期。
QQQ 同时保留 effectiveDate 和 effectiveBusinessDate，as_of 使用后者。

持仓记录：id、ticker（可以为空）、name、asset_class、weight（小数比例，可空）、
duration_years（可空）、yield_pct（百分数，可空）、maturity、原始security_type。
允许官方真实的负现金项；股票贡献只覆盖有非负已知权重且有回报的股票。
不重归一化。未知权重记录数、已知权重合计、可解释权重必须一起显示。

GLD记录：date、close、nav_1030、indicative_1615、midpoint_1615、
premium_pct_1615、ounces_per_share。各字段的时点不能抹平。
节假日空行不补价格；日期重复/无法解析的数字拒绝或显式标为缺失。

存储：`data/asset_sources/<symbol>/<sha256>-<capture-id>.json` 与 `.raw`，
文件名由受控标的、摘要与捕获时间组成；UUID临时文件原子替换。
同一原始字节的不同取得时间可保留；证据选择不会回写文件、刷新known_at。
加载时校验原始摘要；损坏或版本不兼容的文件拒绝进入分析。

两种模式：

* `point_in_time`：持仓as_of<=期初日，available_at<=期初纽约开盘。
  历史档案也需available_at<=分析截止时刻。当前下载不能冒充过去可用数据。
* `retrospective`：允许事后下载官方历史记录，但持仓as_of仍必须<=期初日，
  输出“事后解释，不能作为当时可交易回测”。不存在期初权重时只显示当前结构。

当前QQQ快照是10月2日收盘权重，不能用于归因9月25日至10月2日。
10月1日美债持仓可用于10月1日至2日的事后久期近似，不能用于9月25日起的期间。
当前结构分析可使用截止日以内的最新快照，但必须显示其原始日期。

## 4. 回报口径

价格回报：`close[end]/close[start]-1`，不计现金分红；本项目Yahoo close已处理
拆股，原始数据仍必须保持原始字段与来源。调整回报代理：`adj close`同式，
标为供应商调整序列的总回报代理，不能保证完全重现官方基金回报。
不得把缺失adj close退回close后仍称总回报。
全序列必须索引唯一且递增；拒绝端点缺失、非正数或无限值；不补齐缺失交易日。
日收益不默认forward-fill。期间计算需匹配同一日期，显示price_return和
adjusted_return_proxy及两者差（不是严格现金分红收益）。

国债收益率保持百分数单位；变动bp=`(yield_end-yield_start)*100`，
不是债券投资回报。GC=F 为连续期货报价变动，未处理展期、保证金、抵押收益，
不得称可投资总回报。指数只显示价格指数变动，未提供分红再投资指数。

## 5. 三类专用模块

### QQQ 股票持仓贡献

单一期间买入并持有近似：`contribution_i = start_weight_i * simple_return_i`。
数据采用期初权重，不能以期末权重反推。输出原始权重覆盖率、每只股票贡献、
缺失回报的股票、非股票和未知权重、ETF实际回报、残差。
只有ETF和股票回报使用一致口径时才给残差；阶段一统一价格口径。
残差包括分红、现金、期货、费用、交易与复制误差，不能自动归为某个因果。
多日仍是固定期初权重的期间近似，不能冒充逐日换仓核算。
下一阶段接入每日快照与公司行动后，逐日贡献以财富权重链接，验证贡献和
残差重构实际总回报，再提供行业汇总（分类出处与映射版本必须可追溯）。

### 美债ETF久期敏感性

从官方持仓加权 `D = sum(weight_i * duration_i)`，未重归一化，报告
债券权重/久期已知覆盖率，现金和货币基金分开。单次平行曲线冲击近似
`delta_price ~= -D * delta_yield_bp / 10000`。
实测日归因采用^TNX/IEF、^TYX/TLT单期限代理，标为近似；残差保留。
发行商Convexity单位尚未确认，不直接代入二阶公式。
完整曲线模型下一阶段使用现金流重估或key-rate duration，并考虑票息、
carry、rolldown、费用、分红与曲线非平行变化；不得用到期日桶冒充key-rate duration。

### GLD 与黄金

实现官方档案每股黄金储备变化、10:30 NAV回报、价格回报和16:15官方溢折价。
价格与NAV不同时间，二者回报差仅叫“不同定价时点的回报差”，不能当净跟踪误差。
没有独立spot/LBMA基准时不把NAV除以每股黄金盎司后所得隐含值当独立黄金因子。
GC=F与GLD分别分析，禁止直接比较两者价格水平。
下一阶段取得授权且同时间的黄金基准后，分解黄金价格、每股储备损耗、
净现金项与市场溢折价；期货需明确合约、展期规则和抵押收益。

## 6. 真正因果模型的开发路线

先固定研究问题：例如“意外紧缩25bp，对公告后30分钟QQQ/黄金/10年国债的影响”，
不是泛化的“利率上涨导致资产涨跌”。[Fed研究入口](https://www.federalreserve.gov/econres/feds/the-effect-of-the-federal-reserve-on-the-stock-market-magnitudes-channels-and-shocks.htm)。

数据合同：event_id、UTC公告时间、事件类型、shock_value、shock_unit、
shock_source、publication/available_at、window_start/end、资产窗口前后报价、
交易时区、并发事件标记、央行信息效应识别或分离方式。日线不能代替窄窗口报价。
公众可获取的已发表冲击序列需版本/许可/发布日期；无法获取时状态为not_ready。

按资产分别确定假设图和目标：黄金考虑实际利率/美元/通胀预期；美债考虑
政策路径/通胀/期限溢价；纳指考虑贴现率/盈利预期/风险偏好。
变量的控制角色按“总效应/直接效应”事先决定，避免控制冲击后的中介。
研究采用事件研究与local projections/IV，只有明确工具变量与排除限制时采用IV。
普通OLS、PC图与机器学习异质性估计保留为关联或条件结构分析。

验收：时间顺序留出样本；事件聚类/稳健区间；伪事件与事前窗口检验；
替换窗口/因子口径；弱工具检验（适用时）；高通胀/低通胀等样本外稳定性；
经济量级检查。先注册主要规格，再展示敏感性；拒绝只报告显著结果。
报告同时列样本范围、事件数、估计目标、识别假设、区间、失败检验和外推边界。

## 7. 实施路线与验收

1. **本次交付**：官方数据采集/不可变证据存储、双时间约束、资产类型与回报口径、
   QQQ贡献计算接口、美债结构/敏感性、GLD官方历史指标、离线报告与命令行。
   所有真实缺口必须出现在报告；可重新执行下载和报告，不隐式访问网络。
2. **下一阶段**：开始积累每个交易日的官方快照（自动调度另需用户请求），
   证券标识映射、逐日贡献链接、完整曲线与同时间黄金基准；历史发布时刻验证。
3. **研究阶段**：获取合格政策意外冲击与分钟数据；完成单个研究目标的识别和
   留出验证后再扩展，未通过检验不得升级“因果”标签。
4. **账户阶段（可选）**：用户导入账户标的/数量/估值日期后，基于市值计算真实
   账户权重与穿透风险；不读取未经授权的账户，不假设用户个人配置。

第一阶段验收包括：同一raw摘要可重复核对；损坏文件拒绝；未来快照拒绝；
事后下载无法穿越point_in_time；NaN不产生假回报；收益率单位正确；QQQ包含
现金和衍生品时不重归一化；duration+10bp方向正确；GLD不同时间数据标签正确；
^IXIC/^NDX不会使用QQQ持仓；完整离线测试不访问网络；真实来源独立验证。

设计自审：无需账户数据，官方字段已验证；模型输出与可用输入匹配。
基准授权、历史发布时间、连续期货展期和全曲线模型是明确的后续输入条件，
第一阶段不制造占位数值来填满报告。
