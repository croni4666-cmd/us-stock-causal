# 黄金、美债、纳斯达克专用分析：第一阶段

这是独立的专用分析入口，与原有通用五段报告并存。运行依赖沿用项目锁定环境。
无需个人账户，也无需商业API密钥；分析QQQ时的权重是基金发行商的真实持仓。

## 使用

先显式下载四份官方数据。下载失败会返回非零退出码，不会退回估计权重：

```sh
python -m examples.asset_report sync --symbols QQQ IEF TLT GLD
```

下载写入 `data/asset_sources/`，包含原始资料、摘要和规范化数据。这些资料被
Git忽略，应保留在本地，不要重新分发完整发行商档案。重复下载保留不同的取得时间。

将既有行情下载到 `data/raw/` 后生成报告（支持显式指定别的本地行情目录）：

```sh
python -m examples.asset_report report --symbols GLD GC=F IEF TLT QQQ ^NDX ^IXIC --start 2026-10-01 --end 2026-10-02 --mode retrospective --output output/asset_report.md --json-output output/asset_report.json
```

两个端点必须存在于本地行情，未找到、重复、非正价格或损坏数据会显示数据问题。
部分数据不足时仍输出报告，JSON逐资产状态和原因可以用于上层展示。
报告命令不会访问网络、补价格、刷新数据或修改原始快照。

同一标的存在于多个数据层时，使用显式选择，报告不会猜测。例如：

```sh
python -m examples.asset_report report --symbols GLD --start 2026-09-30 --end 2026-10-01 --mode retrospective --market-file GLD=data/raw/commodities_spot_etf/GLD.parquet
```

`--market-file SYMBOL=PATH` 可重复传入，也可指定成分股文件。JSON保存实际使用
行情文件的摘要和路径；这仅证明计算输入，不证明历史时刻已经可获得。

## 怎样读报告

* `point_in_time` 默认模式限制官方输入的已知时间：持仓所属日期<=期初，
  取得时间<=期初纽约09:30；GLD档案取得时间<=截止日纽约16:30。
  当前行情缓存缺少历史发布/修订时间，因此整个报告仍不能认证为可交易历史回测。
* `retrospective` 允许事后取得历史数据，用于事后解释；期末持仓仍不能归因期初期间。
  例如10月2日QQQ快照不能用于10月1日至2日或此前5日的期初权重贡献。
* “当前结构”与“期间归因”分别显示；当前结构日期可能早于报告截止日。
  不足以进行期间归因时仍可查看官方持仓结构，并看到具体缺口。

价格回报不计现金分红；`adj close`产生“供应商总回报代理”；两者差值不等于
精确现金分红收益。^TNX等是收益率百分数，变化用bp，不是债券投资回报。
GC=F是连续期货报价变化，未核算展期、抵押收益和保证金。^IXIC与^NDX是
不同的价格指数，QQQ基金持仓不会被拿来当这两个指数的官方权重。

QQQ贡献接口使用期初原始股票权重×同口径股票价格回报；缺失行情的股票列入
缺口，现金和期货保留，不把剩余股票权重重归一化到100%。需要本地逐股票行情
和合格的历史期初快照才会启动该计算。多日结果是假设期初权重固定的近似，
并未核算基金逐日换仓。残差不是新的因果因素。

IEF/TLT输出发行商持仓加权久期及+10bp平行冲击的价格敏感性。历史期间满足
期初条件时，使用^TNX/^TYX单期限变化给线性近似，保留价格残差。
它还不包含完整曲线、凸性、票息、carry、rolldown和非平行变动。

GLD输出官方每股黄金储备、纽约10:30 NAV和16:15官方溢折价。GLD市场收盘
与NAV时点不同，不能把二者回报差当净跟踪误差。官方档案中的独立LBMA黄金
基准已移除，没有授权同时间基准就不做该分解。

完成这一步，当前报告的因果状态固定为“未识别”，不会生成虚构的冲击系数。
